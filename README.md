## About This Repository

This repository contains the SQL programs and practical work completed during the Database Management System (DBMS) Laboratory course.

The programs are organized topic-wise to cover various DBMS concepts such as database creation, table creation, queries, set operations, aggregate functions, joins, views, triggers, and constraints.

The practicals are implemented using a University Management Database consisting of students, faculty members, courses, instructors, and related entities.
